# Data artifact provenance

The implemented input is `synthetic-demo-001`, generated by
`python -m nowcast.data generate runs/data-fixture`. The directory must not exist;
the generator refuses to overwrite earlier artifacts. It uses integer arithmetic,
not downloaded observations or a random seed. All timestamps are invented for
integration. No weather skill, Indian location or calibrated hazard is implied.

Observed data: `[12,32,32,1]`, little-endian float32, channel `demo_intensity`,
units `arbitrary_demo_units`, 2026-01-01 00:00 through 00:55 UTC at five-minute
cadence. Orientation is time, image row, image column, channel. No geographic
orientation is asserted. Native/effective spacing, CRS and bounds are null;
use an image panel. There is no resampling or normalization.

`quality-mask.npy` is boolean `[12,32,32,1]`: True means valid and False means
missing/invalid. The first cell in each frame is deliberately missing with a
zero placeholder. Never interpret that placeholder as an observation. The loader
does not impute. Consumers honor the repository convention that True means valid.
The persistence and optical-flow adapters propagate invalid cells as `NaN` while
preserving valid numeric zeros.

Four future synthetic frames (01:00 through 01:15 UTC) live in
`evaluation-targets.npy`, referenced only by `evaluation.json`. Inference JSON
contains no target pointer. `load_event` opens only observed and mask arrays,
returns the contract fields as a dictionary with absolute local artifact paths,
and excludes unknown top-level fields. These paths are not API URLs.

`configs/data/synthetic-provenance.json` records expected SHA256 and byte counts.
Generation writes the same manifest beside the arrays. Checksums are provenance
evidence, not automatically enforced by `load_event`. No binaries are committed.

## SEVIR representation boundary

Primary references checked 2026-09-29:
[AWS registry](https://registry.opendata.aws/sevir/),
[original tutorial](https://github.com/MIT-AI-Accelerator/eie-sevir/blob/master/examples/SEVIR_Tutorial.ipynb),
[generator](https://github.com/MIT-AI-Accelerator/eie-sevir/blob/master/sevir/generator.py).
The AWS registry states no restrictions on data use; this does not establish
separate checkpoint or utility-code licensing.

Original raster storage is `[N,H,W,T]`; an eventual reader must select the
catalog file index, verify its event ID and transpose to `[T,H,W,1]`. VIL has
native 384x384 pixels at 1 km and five-minute intervals. Encoded integers 0..254
are not mm/h; 255 indicates missing data. The loader's `vil` channel convention
uses `SEVIR_encoded_VIL`, rejecting valid pixels containing 255 or fractions.
This is a local channel convention for peer review, not a shared contract change.

The tutorial documents a nonlinear conversion to kg/m². That conversion is not
checkpoint normalization. No physical conversion or learned normalization is
implemented because Manish has not supplied a terms-cleared, hashed checkpoint
and its approved preprocessing configuration. Raw arrays must remain separate
from any future normalized artifact. Satellite brightness is not VIL. The
synthetic channel cannot substitute for checkpoint input.

Unknown geometry stays null even for US events. A future reader must preserve
catalog projection, pixel orientation and timing offsets before deriving bounds;
never transplant a US event to India. No downloaded real event is currently an
inference-ready EventBundle.

## NOAA MRMS archived replay

`nowcast.data.mrms` is a separate, bounded replay path using NOAA's public
`noaa-mrms-pds` bucket and a fixed six-file CONUS `MergedReflectivityQCComposite`
sequence. It retains the product's `dBZ` reflectivity unit. It is explicitly US
archived/replay evidence, not an Indian feed or a forecast-validation claim.

The command reads genuine regular-latitude/longitude GRIB metadata and crops a
fixed native 128x128 panel without resampling. The crop coordinates are recorded
in configuration and were selected from the first observed frame, not future
truth. It records the exact selected source
objects and output checksums in its generated manifest. Four increasing UTC
source timestamps are written to `event.json`; two later timestamps and values
are written only to `evaluation.json` and `evaluation-targets.npy`. Invalid
pixels are false in `quality-mask.npy`, so their stored zero placeholder has no
physical meaning.

For `MergedReflectivityQCComposite_00.50`, documented `-99` missing and `-999`
no-coverage values are explicitly invalidated even when ecCodes does not expose
them through the GRIB `missingValue` key. The two separate targets are only about
+2 and +4 minutes after the final observation; they are not +30/+60 validation.

The selected files have source timestamps near the nominal two-minute interval,
with actual seconds retained from their filenames. The loader accepts up to 30
seconds of inferred-cadence jitter and rejects larger discontinuities.
